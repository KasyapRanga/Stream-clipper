# Music library

On first render the tool downloads free Kevin MacLeod tracks (CC BY 4.0) here and records them in `library.json`.

To use your own royalty-free tracks, drop them into mood folders:

```
music/hype/   music/funny/   music/tense/   music/chill/
```

Files placed directly in `music/` are used for any mood. Only use tracks you have the rights to post.
